# 물고기 외형

청람의 물고기 12종을 그릴 때 참고하는 외형 설명입니다. 이름·등급·길이·시세는 `catalog/fish.json`에 있고, 여기에는 생김새만 적습니다.
그린 그림은 `파일` 칸의 경로로 올리고, `catalog/fish.json`의 그 물고기 `image`에 같은 경로를 적으면 `/낚시` 결과 아래에 크게 보입니다.

## 공통 그림 규칙

| 항목 | 추천 |
|---|---|
| 비율·크기 | **3:1** (넓고 낮게), 1200×400 (최소 600×200) |
| 파일 | 투명 배경 PNG, 1MB 이하, `images/fish/<id>.png` |
| 보이는 크기 | 디스코드 낚시 결과 **맨 아래에 가로 약 400px, 세로 약 130px**로 보입니다. |
| 구도 | **옆모습**, 몸을 가로로 눕혀 **머리가 왼쪽**을 보게 통일. 물고기가 그림 가로의 80~90%를 채우고, 위아래 여백은 거의 두지 않기 |
| 크기 | 실제 길이 차이는 그림 크기로 나타내지 않습니다. 멸치도 참치도 그림을 꽉 채우게 그려 주세요(길이는 결과 글에 cm로 나옴). |
| 빛 | 왼쪽 위에서 오는 빛으로 통일, 비늘이나 피부에 하이라이트 한두 줄 |
| 예외 | 광어는 바닥에 붙어 사는 물고기라 **위에서 본 모습**을 가로로 길게 놓기. 복어·개복치처럼 몸이 둥근 물고기는 **세로를 꽉 채우고** 좌우는 비워도 됩니다(거품·물결로 채워도 좋음). |

## 등급별 분위기

등급마다 테두리 빛을 다르게 하면 결과 화면에서 희귀한 물고기가 한눈에 보입니다(봇의 등급 표시 ⚪🟢🔵🟠와 같은 색).

| 등급 | 분위기 | 빛 효과 |
|---|---|---|
| ⚪ 흔함 | 자연스러운 은색·회색, 단순하고 깔끔하게 | 없음 |
| 🟢 보통 | 색이 또렷하고 무늬가 선명하게 | 아주 약한 초록 테두리 빛 |
| 🔵 희귀 | 생김새가 독특하고 색이 화려하게 | 은은한 파란 테두리 빛 |
| 🟠 전설 | 크고 힘찬 모습, 근육과 지느러미가 살아 있게 | 주황·금빛 반짝임 |

| 🔵 희귀 | 복어 (`cabbage`) | 20~50cm | 공처럼 동그랗게 부푼 몸에 작은 가시가 돋았다. 등은 황갈색에 검은 점, 배는 하얗다. 작은 입과 동그란 눈, 짧은 지느러미가 귀엽지만 독이 있는 느낌. | `images/fish/cabbage.png` |

| 🔵 희귀 | 참돔 (`seabream`) | 30~100cm | 위아래로 높고 둥근 몸. 선명한 분홍빛 붉은색에 작은 파란 점이 흩어져 있고 배는 연분홍. 눈가는 금빛, 꼬리 끝에 검은 테두리. 우아하고 귀한 느낌. | `images/fish/seabream.png` |
| 🟠 전설 | 참치 (`potato`) | 100~300cm | 크고 통통한 어뢰형 몸에 근육이 꽉 찼다. 등은 짙은 남색, 옆구리는 은색, 꼬리 앞에 노란 토막지느러미가 줄지어 있다. 단단한 초승달 꼬리, 빠르게 헤엄치는 힘찬 자세. | `images/fish/potato.png` |
| 🟠 전설 | 청새치 (`marlin`) | 150~400cm | 창처럼 길게 뻗은 뾰족한 주둥이, 돛처럼 높이 솟은 등지느러미. 등은 코발트 블루, 옆구리에 연한 하늘색 세로 줄무늬, 크게 갈라진 초승달 꼬리. 물을 박차고 튀어 오르는 듯한 자세. | `images/fish/marlin.png` |
| 🟠 전설 | 개복치 (`sunfish`) | 100~330cm | 꼬리가 잘린 듯 둥글고 납작한 원반 같은 거대한 몸. 위아래로 길게 뻗은 등지느러미와 뒷지느러미, 몸 끝은 주름진 꼬리. 회은색 거친 피부, 작은 입과 멍한 눈이 엉뚱하고 신비로운 느낌. | `images/fish/sunfish.png` |

## 황금 물고기

황금 물고기(황금 멸치·황금 참치 등)는 지금 **보통 물고기와 같은 그림**을 씁니다. 따로 그리지 않아도 됩니다.

황금 그림을 따로 쓰고 싶으면, 같은 모양에 몸 전체를 반짝이는 금빛으로 칠하고 둘레에 작은 반짝임 입자를 두르면 됩니다(파일 예: `images/fish/golden_potato.png`). 이 그림을 쓰려면 봇을 고쳐야 하니 그때 말씀해 주세요.
