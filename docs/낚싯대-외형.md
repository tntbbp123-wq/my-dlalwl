# 낚싯대 외형

청람의 낚싯대 5종을 그리거나 이미지 생성 도구로 만들 때 참고하는 외형 설명입니다. 수치(가격·내구도·효과)는 봇 코드(`src/fish-data.js`)에 있고, 여기에는 생김새만 적습니다.
만든 그림은 `파일` 칸의 경로로 올리고, `catalog/rods.json`의 그 낚싯대 `image`에 같은 경로를 적으면 `/낚싯대` 상점(지금 낚싯대)과 `/낚시`·어선 결과(쓴 낚싯대)의 **왼쪽 위**에 낚싯대 이름과 함께 작게 보입니다.

## 공통 그림 규칙

지금 올라가 있는 그림(`images/rods/`)이 기준입니다. 디스코드가 아이콘을 동그랗게 자르므로 **낚싯대 전체가 가운데 원 안에** 들어가게 그립니다.

| 항목 | 추천 |
|---|---|
| 비율·크기 | **1:1** (정사각형), 256×256 (최소 128×128). 더 크게 그려도 보이는 크기는 같아요 |
| 파일 | **투명 배경** PNG, 1MB 이하(작은 그림이라 보통 100KB 안쪽), `images/rods/<id>.png` |
| 보이는 크기 | 메시지 **왼쪽 위에 약 24px**, **동그랗게 잘려** 보입니다(이름 글자 바로 앞의 작은 아이콘) |
| 구도 | 대를 **45° 대각선으로**: 손잡이 끝은 왼쪽 아래, 대 끝은 오른쪽 위. 네 모서리는 잘리므로 손잡이 끝과 대 끝은 모서리에서 13~15% 안쪽에 두고, 대 전체와 효과가 가운데 원 안에 들어가게 |
| 릴 | 손잡이 바로 위, 대의 **오른쪽 아래**에 크게(그림 폭의 약 5분의 1). 작은 아이콘에서는 릴과 손잡이 색으로 낚싯대를 알아봐요 |
| 단순하게 | 대는 그림 폭의 10~12%로 굵게, 외곽선은 **진한 검정으로 두껍게**(256×256 기준 4px쯤). 대에는 마디 고리 2~3개만. 낚싯줄·찌는 그리지 않기 |
| 통일 | 5종 모두 같은 각도(45°)·같은 굵기·같은 릴 크기와 위치·같은 빛 방향(왼쪽 위) |
| 등급 느낌 | 좋은 낚싯대일수록 재료가 고급스러워지고 효과가 늘어남(색은 장비 등급 색과 맞춤). 반짝임·번개 같은 효과는 **대에 바짝 붙여 작게** 그려야 작은 아이콘에서 지저분해지지 않아요 |

## 이미지 생성 프롬프트

이미지 생성 도구에는 **공통 문장 + 낚싯대 이름과 외형**(아래 표의 `외형` 칸)을 이어 붙여 한 번에 넣으세요. 등급 효과는 `외형` 칸에 들어 있습니다.
5종 모두 같은 공통 문장을 써야 그림체가 맞습니다. 지금 그림 중 하나를 함께 넣고 `이 그림과 같은 그림체와 구도로`를 더하면 가장 비슷하게 나옵니다.

**공통 문장**

```
2D 게임 아이템 아이콘, 아주 굵고 진한 검은 외곽선과 단순한 셀 셰이딩, 선명한 색.
정사각형 1:1(256×256) 그림. 아주 작게 줄여도 알아볼 수 있게 단순하게.
낚싯대 하나만 45° 대각선으로 놓고, 손잡이 끝은 왼쪽 아래, 대 끝은 오른쪽 위.
낚싯대 전체와 효과가 그림 가운데 원 안에 들어가고, 네 모서리는 비어 있다.
릴은 손잡이 바로 위, 대의 오른쪽 아래에 크게 단다.
대는 굵고, 마디 고리는 2~3개만. 낚싯줄·찌는 없다.
빛은 왼쪽 위에서 온다.
투명 배경, 물·바닥·그림자 없음. 글자·숫자·워터마크·테두리 없음.
```

**예시 (대나무 낚싯대)**

```
2D 게임 아이템 아이콘, 아주 굵고 진한 검은 외곽선과 단순한 셀 셰이딩, 선명한 색.
정사각형 1:1(256×256) 그림. 아주 작게 줄여도 알아볼 수 있게 단순하게.
낚싯대 하나만 45° 대각선으로 놓고, 손잡이 끝은 왼쪽 아래, 대 끝은 오른쪽 위.
낚싯대 전체와 효과가 그림 가운데 원 안에 들어가고, 네 모서리는 비어 있다.
릴은 손잡이 바로 위, 대의 오른쪽 아래에 크게 단다.
대는 굵고, 마디 고리는 2~3개만. 낚싯줄·찌는 없다.
빛은 왼쪽 위에서 온다.
투명 배경, 물·바닥·그림자 없음. 글자·숫자·워터마크·테두리 없음.
대나무 낚싯대: 연갈색 대나무 대에 볼록한 마디 3개, 짙은 갈색 끈을 감은 손잡이, 둥근 갈색 나무 릴에 작은 나무 손잡이. 소박한 느낌, 빛 효과 없음.
```

**생성 도구 팁**

| 상황 | 이렇게 |
|---|---|
| 크기 | 대부분의 도구가 1:1을 고를 수 있어요. 크게(예: 1024×1024) 만들었으면 256×256으로 줄여서 올리기 |
| 투명 배경이 안 됨 | `투명 배경` 대신 `낚싯대에 없는 색의 단색 배경`으로 만들고, 배경 지우기 도구로 지우기 |
| 낚싯대 끝이 모서리까지 닿음 | 프롬프트 끝에 `낚싯대 양 끝이 모서리에서 떨어져 원 안에 들어가게.`를 더하기. 다 만든 그림이면 둘레에 투명 여백을 넣어 75%쯤으로 줄이기 |
| 너무 복잡하게 나옴 | 프롬프트 끝에 `선과 색을 최대한 줄인 단순한 아이콘.`을 더하기 |
| 그림체가 들쭉날쭉함 | 지금 그림을 함께 넣고 `이 그림과 같은 그림체와 구도로`를 더하기 |
| 영어만 잘 알아듣는 도구 | 이어 붙인 프롬프트를 통째로 영어로 번역해서 넣기 |
| 다 만든 뒤 | 동그랗게 잘라 봤을 때 양 끝이 잘리지 않는지, 24px로 줄였을 때 릴과 손잡이 색으로 어떤 낚싯대인지 알아볼 수 있는지 확인하기 |
