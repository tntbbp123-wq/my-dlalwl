# 낚싯대 외형

청람의 낚싯대 5종을 그릴 때 참고하는 외형 설명입니다. 수치(가격·내구도·효과)는 봇 코드(`src/fish-data.js`)에 있고, 여기에는 생김새만 적습니다.

> 지금 봇은 낚싯대 이미지를 아직 보여 주지 않습니다. 이미지를 올려 두면 `/낚싯대` 상점과 낚시 결과에 붙이도록 봇을 고칠 수 있습니다.

## 공통 그림 규칙

| 항목 | 추천 |
|---|---|
| 비율·크기 | **1:1**, 512×512 (최소 256×256) |
| 파일 | 투명 배경 PNG, 1MB 이하, `images/rods/<id>.png` |
| 구도 | 대를 **왼쪽 아래 → 오른쪽 위 대각선**으로, 손잡이와 릴은 왼쪽 아래, 대 끝에서 낚싯줄이 아래로 늘어지고 끝에 찌 |
| 여백 | 가장자리 10% 정도 비우기 (디스코드에서 작게 보여도 잘리지 않게) |
| 통일 | 5종 모두 같은 각도·같은 굵기 비율·같은 빛 방향(왼쪽 위) |
| 등급 느낌 | 좋은 낚싯대일수록 재료가 고급스러워지고 반짝임·빛이 늘어남 (색은 장비 등급 색과 맞춤) |

## 낚싯대 5종

| 낚싯대 | 파일 | 등급 느낌 | 외형 |
|---|---|---|---|
| 대나무 낚싯대 | `images/rods/bamboo.png` | ⚪ 일반 (빛 없음) | 마디가 또렷한 연노란 대나무 대. 손잡이에 거친 삼끈을 칭칭 감았고, 작고 단순한 나무 릴이 달려 있다. 흰 낚싯줄 끝에 빨강·흰색 반반인 둥근 찌. 소박하고 손때 묻은 느낌. |
| 카본 낚싯대 | `images/rods/carbon.png` | 🟢 고급 (초록 포인트) | 매끈한 검은 카본 섬유 대에 격자 무늬가 은은하게 보인다. 손잡이는 초록 고무 그립, 은색 금속 릴. 대를 따라 작은 은색 가이드 링이 3~4개. 투명한 낚싯줄, 초록 찌. 가볍고 날렵한 느낌. |
| 강철 낚싯대 | `images/rods/steel.png` | 🔵 희귀 (파란 빛) | 은빛으로 빛나는 단단한 강철 대. 묵직한 금속 릴에 파란 손잡이 그립, 릴 옆에 작은 파란 보석. 가이드 링이 반짝이고, 대 끝이 살짝 휘어 힘이 느껴진다. 파란 찌, 낚싯줄에 은은한 푸른 광택. |
| 황금 낚싯대 | `images/rods/gold.png` | 🟠 전설 (금·주황 빛) | 황금으로 만든 대에 덩굴 무늬 조각. 릴은 보석이 박힌 금 원판이고, 손잡이는 짙은 갈색 가죽에 금실 자수. 낚싯줄이 금빛으로 빛나고, 찌 대신 작은 금방울. 대 주변에 주황빛 반짝임. |
| 전설의 낚싯대 | `images/rods/legend.png` | 🔴 신화 (붉은 빛·바다) | 바다를 굳혀 만든 듯 투명한 푸른 대 안에 물결과 작은 별빛이 흐른다. 릴은 산호와 조개로 장식된 진주빛 원판, 손잡이는 붉은 비늘 무늬. 낚싯줄은 붉은 빛줄기, 끝에 찌 대신 빛나는 진주. 대 주위로 붉은 빛 입자와 물방울이 떠다닌다. |
