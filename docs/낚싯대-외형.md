# 낚싯대 외형

청람의 낚싯대 5종을 그리거나 이미지 생성 도구로 만들 때 참고하는 외형 설명입니다. 수치(가격·내구도·효과)는 봇 코드(`src/fish-data.js`)에 있고, 여기에는 생김새만 적습니다.
만든 그림은 `파일` 칸의 경로로 올리고, `catalog/rods.json`의 그 낚싯대 `image`에 같은 경로를 적으면 `/낚싯대` 상점(지금 낚싯대)과 `/낚시`·어선 결과(쓴 낚싯대)의 **왼쪽 위**에 낚싯대 이름과 함께 작게 보입니다.

## 공통 그림 규칙

| 항목 | 추천 |
|---|---|
| 비율·크기 | **1:1** (정사각형), 256×256 (최소 128×128). 더 크게 그려도 보이는 크기는 같아요 |
| 파일 | 투명 배경 PNG, 1MB 이하(작은 그림이라 보통 100KB 안쪽), `images/rods/<id>.png` |
| 보이는 크기 | 메시지 **왼쪽 위에 약 24px**, **동그랗게 잘려** 보입니다(이름 글자 바로 앞의 작은 아이콘) |
| 구도 | 대를 **대각선으로**: 손잡이와 릴은 왼쪽 아래, 대 끝은 오른쪽 위. 네 모서리가 잘리므로 손잡이 끝과 대 끝은 모서리에서 15% 이상 안쪽에 두고, 대 전체가 가운데 원 안에 들어가게 |
| 단순하게 | 작게 보이니 대·릴·손잡이 색만 또렷하게. 대는 그림 폭의 8~10%쯤으로 굵게, 테두리는 진하게. 낚싯줄·찌·가이드 링 같은 잔 부분은 빼거나 크게 줄이기 |
| 배경 | 투명 배경을 권합니다. 작은 크기에서 더 잘 보이게 하려면 등급 색의 동그란 배경을 깔아도 좋아요(5종 모두 같은 방식으로) |
| 통일 | 5종 모두 같은 각도(45°)·같은 굵기 비율·같은 빛 방향(왼쪽 위) |
| 등급 느낌 | 좋은 낚싯대일수록 재료가 고급스러워지고 반짝임·빛이 늘어남 (색은 장비 등급 색과 맞춤) |

작은 그림이라 잔 무늬·가는 낚싯줄·찌는 거의 안 보입니다. 아래 외형은 **대표 색과 재료 느낌, 굵은 실루엣**만 남겨 적었습니다.

## 이미지 생성 프롬프트

이미지 생성 도구에는 **공통 문장 + 낚싯대 이름과 외형**(아래 표의 `외형` 칸)을 이어 붙여 한 번에 넣으세요. 등급 빛은 `외형` 칸에 들어 있습니다.
5종 모두 같은 공통 문장을 써야 그림체가 맞습니다.

**공통 문장**

```
2D 게임 아이템 아이콘, 아주 굵고 진한 외곽선과 단순한 셀 셰이딩, 선명한 색.
정사각형 1:1(256×256) 그림. 아주 작게 줄여도 알아볼 수 있게 단순하게.
낚싯대 하나만 45° 대각선으로 놓고, 손잡이와 릴은 왼쪽 아래, 대 끝은 오른쪽 위.
낚싯대 전체가 그림 가운데 원 안에 들어가고, 네 모서리는 비어 있다.
대는 굵고, 잔무늬·가는 낚싯줄·찌는 없다.
빛은 왼쪽 위에서 온다.
투명 배경, 물·바닥·그림자 없음. 글자·숫자·워터마크·테두리 없음.
```

**예시 (대나무 낚싯대)**

```
2D 게임 아이템 아이콘, 아주 굵고 진한 외곽선과 단순한 셀 셰이딩, 선명한 색.
정사각형 1:1(256×256) 그림. 아주 작게 줄여도 알아볼 수 있게 단순하게.
낚싯대 하나만 45° 대각선으로 놓고, 손잡이와 릴은 왼쪽 아래, 대 끝은 오른쪽 위.
낚싯대 전체가 그림 가운데 원 안에 들어가고, 네 모서리는 비어 있다.
대는 굵고, 잔무늬·가는 낚싯줄·찌는 없다.
빛은 왼쪽 위에서 온다.
투명 배경, 물·바닥·그림자 없음. 글자·숫자·워터마크·테두리 없음.
대나무 낚싯대: 연노란 대나무 대에 굵은 마디 3~4개, 손잡이에 갈색 삼끈을 감았고, 작은 갈색 나무 릴. 소박한 느낌, 빛 효과 없음.
```

**생성 도구 팁**

| 상황 | 이렇게 |
|---|---|
| 크기 | 대부분의 도구가 1:1을 고를 수 있어요. 크게(예: 1024×1024) 만들었으면 256×256으로 줄여서 올리기 |
| 투명 배경이 안 됨 | `투명 배경` 대신 `낚싯대에 없는 색의 단색 배경`으로 만들고, 배경 지우기 도구로 지우기 |
| 배경을 깔고 싶음 | `투명 배경` 대신 `등급 색의 단색 동그라미 배경`으로 바꾸기(5종 모두 같은 방식으로) |
| 너무 복잡하게 나옴 | 프롬프트 끝에 `선과 색을 최대한 줄인 단순한 아이콘.`을 더하기 |
| 그림체가 들쭉날쭉함 | 처음 잘 나온 그림을 함께 넣고 `이 그림과 같은 그림체로`를 더하기 |
| 영어만 잘 알아듣는 도구 | 이어 붙인 프롬프트를 통째로 영어로 번역해서 넣기 |
| 다 만든 뒤 | 24px로 줄이고 동그랗게 잘라 봤을 때 어떤 낚싯대인지 알아볼 수 있는지 확인하기 |
