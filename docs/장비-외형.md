# 장비 외형

청람의 장비 180종(도감 번호 No.001~No.180)을 그리거나 이미지 생성 도구로 만들 때 참고하는 외형 설명입니다. 이름·등급·능력치 배율은 `catalog/equipment.json`에 있고, 여기에는 생김새만 적습니다.
만든 그림은 `파일` 칸의 경로로 올리고, `catalog/equipment.json`의 그 장비 `image`에 같은 경로를 적으면 장비 창 맨 아래에 크게 보입니다.

## 공통 그림 규칙

| 항목 | 추천 |
|---|---|
| 비율·크기 | **3:1** (넓고 낮게), 1200×400 (최소 600×200) |
| 파일 | 투명 배경 PNG, 1MB 이하, `images/equipment/<번호 3자리>.png` |
| 보이는 크기 | 디스코드 장비 창 **맨 아래에 가로 약 400px, 세로 약 130px**로 보입니다. 세로가 낮으니 잔무늬보다 **실루엣과 색**으로 구분되게 그려 주세요. |
| 구도 | 물건 하나만 가운데, 위아래 여백은 거의 두지 않기, 빛 방향은 왼쪽 위로 통일 |
| 무기 | **가로로 눕혀** 손잡이는 왼쪽, 날끝은 오른쪽으로 그림 가로를 거의 채우기. 활·석궁도 가로로 눕히고, 쌍검은 위아래로 나란히 |
| 갑옷 | **정면**, 몸통 갑옷만(머리·팔다리 없이) 가운데에 세로를 꽉 채워서. 로브·망토·외투는 양옆으로 넓게 펼친 모양이면 가로도 채울 수 있어요. 남는 좌우는 비우거나 등급 빛으로 채우기 |
| 장신구 | 가운데에 세로를 꽉 채워서, 보석이 잘 보이게. 목걸이는 사슬을 양옆으로 넓게 펼치고, 귀걸이 한 쌍은 좌우로 나란히, 반지·부적은 가운데에 두고 양옆을 등급 빛으로 채우기 |

## 등급별 분위기

같은 등급끼리는 재료·색·빛을 맞추면 도감에서 등급이 한눈에 보입니다.

| 등급 | 색 | 재료·분위기 | 빛 효과 |
|---|---|---|---|
| ⚪ 일반 | 회색·갈색 | 나무, 녹슨 쇠, 천, 가죽 — 낡고 소박함 | 없음 |
| 🟢 고급 | 초록 포인트 | 깨끗한 강철·은 — 단정하고 튼튼함 | 아주 약한 초록 광택 |
| 🔵 희귀 | 파랑 | 은, 보석, 문장·룬 각인 | 은은한 파란 빛 |
| 🟣 영웅 | 보라 | 정교한 문양, 마력이 깃든 재료 | 보라 오라 |
| 🟠 전설 | 금·주황 | 황금 장식, 화려하고 장엄함 | 주황 빛과 반짝임 |
| 🔴 신화 | 빨강·우주 | 신성한 재료, 별·은하·심연 | 붉은 오라와 빛 입자 |

## 이미지 생성 프롬프트

이미지 생성 도구에는 **공통 문장 + 종류 문장 + 등급 문장 + 장비 이름과 외형**(아래 표의 `외형` 칸)을 이어 붙여 한 번에 넣으세요.
180종 모두 같은 공통 문장을 써야 도감에서 그림체가 맞습니다. 그림체를 바꾸고 싶으면 첫 줄만 바꾸고, 바꾼 문장을 모두에 똑같이 쓰세요.

**공통 문장**

```
2D 판타지 게임 아이템 일러스트, 진한 외곽선과 부드러운 셀 셰이딩, 선명한 색.
가로세로 3:1(1200×400)의 넓고 낮은 그림.
장비 하나만 그림 가운데에 크게, 위아래 여백은 거의 없다.
빛은 왼쪽 위에서 온다.
투명 배경, 사람·손·바닥·그림자 없음. 글자·숫자·워터마크·테두리 없음.
```

**종류 문장**: 이름에 맞는 줄을 하나 고르세요(없으면 그 종류의 기본 줄).

| 종류 | 이름 | 붙일 문장 |
|---|---|---|
| 🗡️ 무기 | 기본(검·대검·단검·도끼·창·낫·망치·철퇴·몽둥이·채찍·지팡이) | `무기를 가로로 눕혀 손잡이는 왼쪽, 끝은 오른쪽으로 두고 그림 가로를 거의 채운다.` |
| 🗡️ 무기 | 활·장궁 | `활을 가로로 눕혀 그림 가로를 거의 채우고, 시위는 아래쪽에 둔다.` |
| 🗡️ 무기 | 석궁 | `석궁을 옆에서 본 모습으로, 개머리는 왼쪽, 활대는 오른쪽에 두고 그림 가로를 거의 채운다.` |
| 🗡️ 무기 | 쌍검 | `칼 두 자루를 가로로 눕혀 위아래로 나란히 놓고, 손잡이는 왼쪽에 둔다.` |
| 🛡️ 갑옷 | 기본(갑옷·흉갑·조끼) | `몸통 갑옷만 정면으로, 그림 가운데에 세로를 꽉 채운다. 머리·팔다리 없음. 좌우의 빈 곳은 비우거나 등급 빛으로 채운다.` |
| 🛡️ 갑옷 | 로브·망토·외투 | `옷만 정면에서 양옆으로 넓게 펼친 모양으로, 세로를 꽉 채우고 가로도 넓게 채운다. 머리·팔다리 없음.` |
| 💍 장신구 | 기본(반지·팔찌·부적·브로치·동전·휘장) | `장신구 하나를 그림 가운데에 세로를 꽉 채워 크게, 보석이 잘 보이게. 양옆은 등급 빛으로 채운다.` |
| 💍 장신구 | 목걸이 | `목걸이를 정면에서, 사슬을 양옆으로 넓게 펼치고 펜던트는 가운데에 세로를 꽉 채워 크게.` |
| 💍 장신구 | 귀걸이 | `귀걸이 한 쌍을 좌우로 나란히, 세로를 꽉 채워 크게.` |

**등급 문장**

| 등급 | 붙일 문장 |
|---|---|
| ⚪ 일반 | `회색·갈색의 낡고 소박한 재료(나무, 녹슨 쇠, 천, 가죽), 빛 효과 없음.` |
| 🟢 고급 | `깨끗한 강철·은으로 단정하고 튼튼한 모습, 초록 포인트, 아주 약한 초록 광택.` |
| 🔵 희귀 | `은과 보석, 문장·룬 각인, 파란 포인트, 은은한 파란 빛.` |
| 🟣 영웅 | `정교한 문양과 마력이 깃든 재료, 보라 포인트, 보라 오라.` |
| 🟠 전설 | `황금 장식으로 화려하고 장엄한 모습, 금·주황 포인트, 주황 빛과 반짝임.` |
| 🔴 신화 | `신성한 재료와 별·은하·심연의 느낌, 빨강 포인트, 붉은 오라와 빛 입자.` |

**예시 (No.011 강철 검)**

```
2D 판타지 게임 아이템 일러스트, 진한 외곽선과 부드러운 셀 셰이딩, 선명한 색.
가로세로 3:1(1200×400)의 넓고 낮은 그림.
장비 하나만 그림 가운데에 크게, 위아래 여백은 거의 없다.
빛은 왼쪽 위에서 온다.
투명 배경, 사람·손·바닥·그림자 없음. 글자·숫자·워터마크·테두리 없음.
무기를 가로로 눕혀 손잡이는 왼쪽, 끝은 오른쪽으로 두고 그림 가로를 거의 채운다.
깨끗한 강철·은으로 단정하고 튼튼한 모습, 초록 포인트, 아주 약한 초록 광택.
강철 검: 곧고 반짝이는 강철 양날검. 초록 가죽 손잡이와 둥근 폼멜.
```

**생성 도구 팁**

| 상황 | 이렇게 |
|---|---|
| 3:1을 고를 수 없음 | 고를 수 있는 가장 넓은 비율(16:9, 3:2 등)로 만들고, 프롬프트 끝에 `장비는 그림 세로 가운데 절반 안에 두고, 위아래는 빈 배경.`을 더한 뒤 위아래를 잘라 1200×400으로 맞추기 |
| 투명 배경이 안 됨 | `투명 배경` 대신 `장비에 없는 색의 단색 배경`으로 만들고, 배경 지우기 도구로 지우기 |
| 그림체가 들쭉날쭉함 | 처음 잘 나온 그림을 함께 넣고 `이 그림과 같은 그림체로`를 더하기. 공통 문장은 고치지 않기 |
| 영어만 잘 알아듣는 도구 | 이어 붙인 프롬프트를 통째로 영어로 번역해서 넣기 |
| 다 만든 뒤 | 가로 400px로 줄여 봤을 때 무엇인지 알아볼 수 있는지 확인하기 |
