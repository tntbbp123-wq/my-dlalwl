# 청람 물고기·장비 목록과 이미지

디스코드 봇 **청람**이 쓰는 물고기·장비 목록과 그 이미지, 낚싯대 그림을 모아 두는 저장소입니다.
봇은 **시작할 때** 이 저장소의 `catalog/fish.json`·`catalog/equipment.json`·`catalog/rods.json`을 받아 쓰고, 이미지는 디스코드가 이 저장소 주소에서 바로 가져와 보여 줍니다.

```
catalog/
  fish.json        물고기 종류 (지금 12종)
  equipment.json   장비 종류 (지금 180종, 도감 번호 No.001~No.180)
  rods.json        낚싯대 5종의 그림
images/
  fish/            물고기 이미지 (예: images/fish/rice.png)
  equipment/       장비 이미지 (예: images/equipment/001.png)
  rods/            낚싯대 이미지 (예: images/rods/bamboo.png)
```

## 바꾼 내용이 봇에 들어가는 때

- 이 저장소를 고친 뒤 **봇을 다시 켜면** 새 목록을 받아 씁니다(GitHub 반영에 몇 분 걸릴 수 있어요).
- 받은 목록에 잘못된 곳이 있으면 봇은 그 파일을 쓰지 않고, 마지막으로 잘 받았던 목록(봇 데이터 폴더의 `catalog-cache`)이나 봇에 들어 있는 기본 목록을 씁니다. 콘솔에 무엇이 잘못됐는지 적습니다.
- 저장소에 닿지 못해도(인터넷 막힘 등) 같은 방식으로 마지막 목록이나 기본 목록을 씁니다.

## 꼭 지켜야 할 규칙

저장된 게임 데이터가 물고기 `id`와 장비 `no`(도감 번호)를 가리키고 있어서, 아래를 어기면 봇이 그 파일을 쓰지 않습니다.

- **지우지 마세요.** 지금 있는 물고기 `id`, 장비 `no`는 모두 남아 있어야 합니다.
- **바꾸지 마세요.** 물고기의 `id`·`tier`, 장비의 `no`·`type`·`grade`는 그대로 두세요.
- **새로 넣을 때는 맨 뒤에.** 새 장비는 지금 가장 큰 번호 다음 번호(181, 182 …)로, 새 물고기는 새 `id`로 맨 뒤에 붙입니다.
- 이름·길이·시세·경험치·색·능력치 배율·이미지는 자유롭게 바꿔도 됩니다.
- JSON 문법(쉼표, 따옴표)을 지켜 주세요. 마지막 항목 뒤에는 쉼표가 없습니다.

## 물고기 (`catalog/fish.json`)

| 필드 | 뜻 | 규칙 |
|---|---|---|
| `id` | 저장용 이름 | 영어 소문자·숫자·`_`, `golden_`으로 시작하면 안 됨. 멸치·고등어·참치·복어는 예전 이름(`rice`·`carrot`·`potato`·`cabbage`)을 그대로 씀 |
| `name` | 화면에 보이는 이름 | 1~20자. 황금 물고기는 앞에 `황금`이 자동으로 붙음 |
| `tier` | 등급 | `common`(흔함) · `uncommon`(보통) · `rare`(희귀) · `legendary`(전설). 등급마다 1종 이상 |
| `minLength`, `maxLength` | 최소·최대 길이(cm) | 0보다 크고, 최소 < 최대 ≤ 10,000 |
| `price` | cm당 시세 범위(원) `[최저, 최고]` | 정수, 1 ≤ 최저 < 최고 |
| `xp` | 낚으면 받는 경험치 | 0 이상 정수 |
| `color` | 색(예비) | `#a9c4dc` 같은 색 코드 |
| `image` | 이미지 | 아래 "이미지" 참고. 없으면 `null` |

같은 등급의 물고기는 그 등급 확률을 똑같이 나눠 갖습니다. 등급 확률(레벨별)과 낚싯대는 봇 코드(`src/fish-data.js`)에 있습니다.

## 장비 (`catalog/equipment.json`)

| 필드 | 뜻 | 규칙 |
|---|---|---|
| `no` | 도감 번호 | 1 이상 정수, 겹치면 안 됨 |
| `type` | 종류 | `weapon`(무기) · `armor`(갑옷) · `accessory`(장신구) |
| `grade` | 등급 | `common`(일반) · `uncommon`(고급) · `rare`(희귀) · `epic`(영웅) · `legendary`(전설) · `mythic`(신화). 종류·등급마다 1종 이상 |
| `name` | 화면에 보이는 이름 | 1~30자 |
| `statPercent` | 능력치 배율(%) | 1~1,000. 등급 기본 능력치(공격력·방어력·장신구 효과)에 곱함 |
| `image` | 이미지 | 아래 "이미지" 참고. 없으면 `null` |

각 종류·등급의 첫 번째(번호가 가장 작은) 장비는 예전에 얻은 장비가 옮겨 가는 칸이라 `statPercent`를 100으로 두는 것을 권합니다. 등급별 기본 능력치·착용 레벨·강화 규칙은 봇 코드(`src/equipment-system.js`)에 있습니다.

## 낚싯대 (`catalog/rods.json`)

낚싯대의 이름·가격·내구도·효과는 봇 코드(`src/fish-data.js`)에 있고, 이 파일에서는 **그림만** 정합니다. 새 낚싯대는 여기서 넣을 수 없습니다.

| 필드 | 뜻 | 규칙 |
|---|---|---|
| `id` | 낚싯대 | `bamboo`(대나무) · `carbon`(카본) · `steel`(강철) · `gold`(황금) · `legend`(전설의) 중 하나, 겹치면 안 됨 |
| `image` | 이미지 | 아래 "이미지" 참고. 없으면 `null` |

목록에서 빠진 낚싯대는 그림 없이 보입니다.

## 이미지

1. 이미지 파일을 `images/fish/`, `images/equipment/`, `images/rods/`에 올립니다. 이름은 `images/fish/<id>.png`, `images/equipment/<번호 3자리>.png`, `images/rods/<id>.png`를 권합니다(예: `images/fish/potato.png`, `images/equipment/024.png`, `images/rods/bamboo.png`).
2. 목록 파일의 그 항목 `image`에 저장소 안의 경로를 적습니다. 예: `"image": "images/fish/potato.png"`
   - 다른 곳에 올린 이미지는 `https://`로 시작하는 주소를 그대로 적어도 됩니다.
3. 봇을 다시 켜면 보입니다.
   - 물고기 이미지: `/낚시`로 그 물고기를 낚았을 때 결과 아래에 크게(황금 물고기도 같은 이미지)
   - 장비 이미지: `/인벤토리`에서 장비를 골랐을 때 장비 창 아래에 크게
   - 낚싯대 이미지: `/낚싯대` 상점(지금 낚싯대)과 `/낚시`·어선 결과(쓴 낚싯대)의 **왼쪽 위**에 낚싯대 이름과 함께 작게

### 추천 비율·크기

| 이미지 | 비율 | 추천 크기 | 봇에서 보이는 곳 |
|---|---|---|---|
| 물고기 | **3:1** | 1200×400 (최소 600×200) | `/낚시` 결과 아래 — 물고기를 가로로 눕혀 머리가 왼쪽 |
| 장비 | **3:1** | 1200×400 (최소 600×200) | 장비 창 아래 — 무기는 가로로 눕히고, 갑옷·장신구는 가운데에 세로를 꽉 채워서 |
| 낚싯대 | **1:1** | 256×256 (최소 128×128) | 메시지 왼쪽 위 — 대를 대각선으로, 동그란 테두리 안에 |

- 물고기·장비 이미지는 메시지 **맨 아래에 넓고 낮게** 들어갑니다. 디스코드에서는 가로 약 400px, 세로 약 130px로 보이니 위아래 여백은 거의 두지 말고 물건을 크게 그려 주세요.
- 낚싯대 이미지는 메시지 **왼쪽 위에 아주 작게(약 24px) 동그랗게 잘려** 보입니다. 네 모서리는 잘리니 대 전체를 가운데 원 안에 넣고, 굵고 단순하게 그려 주세요.

- 모두 **투명 배경 PNG**를 권합니다(디스코드 다크·라이트 모드 모두에서 자연스러움). 형식은 PNG·JPG·GIF·WebP를 쓸 수 있습니다.
- 한 장에 1MB 이하, 가장자리 10%쯤 여백을 두면 작게 보여도 잘리지 않습니다.
- 같은 종류끼리 시점·빛 방향(왼쪽 위)·선 굵기를 맞추면 도감에서 보기 좋습니다.
- 이 저장소는 **공개 저장소**여야 디스코드가 이미지를 가져올 수 있습니다.

### 외형 설명

그림을 그리거나 맡기거나, 이미지 생성 도구로 만들 때 참고하세요. 문서마다 **복사해서 쓰는 프롬프트**(공통 문장 + 종류·등급 문장 + 외형)와 생성 도구 팁이 있습니다.

- [장비 외형](docs/장비-외형.md): 장비 180종의 생김새, 등급별 분위기(색·재료·빛), 종류별 구도, 파일 이름
- [물고기 외형](docs/물고기-외형.md): 물고기 12종의 생김새, 등급별 분위기, 구도가 다른 물고기, 황금 물고기 안내
- [낚싯대 외형](docs/낚싯대-외형.md): 낚싯대 5종의 생김새와 그림 규칙(1:1, 왼쪽 위 작은 그림, 대 전체를 원 안에)
